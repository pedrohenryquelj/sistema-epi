# Sistema de Gestão de EPIs - CBS

Este é um projeto em Python desenvolvido para automatizar e facilitar o controle de estoque, contagem e registro de trocas de Equipamentos de Proteção Individual (EPIs) na empresa. O objetivo é substituir controles manuais por um sistema eficiente e de fácil manutenção.

## 🚧 Status do Projeto

Em desenvolvimento (Fase de estruturação inicial).

## 🎯 Objetivos e Funcionalidades (Previstas)

* **Controle de Estoque:** Cadastro, contagem e monitoramento da quantidade de EPIs disponíveis.
* **Registro de Movimentação:** Histórico de retiradas, devoluções e trocas de equipamentos pelos funcionários.
* **Gestão de Validade:** Acompanhamento do tempo de vida útil de cada equipamento.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Ambiente:** `venv` para isolamento de dependências.

## 📁 Estrutura do Projeto

O projeto está todo concentrado na pasta principal, contendo os arquivos do código-fonte, o arquivo de configuração de dependências (`requirements.txt`) e o ambiente virtual (`venv`) para garantir o isolamento das bibliotecas utilizadas.

## 🚀 Como Executar (Ambiente de Desenvolvimento)

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/pedrohenryquelj/sistema-epi.git
   cd sistema-epi
   ```

2. **Ative o ambiente virtual:**
   * No Windows:
     ```bash
     venv\Scripts\activate
     ```
   * No Linux/Mac:
     ```bash
     source venv/bin/activate
     ```

3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
